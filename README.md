
# 🏨 Hotel Management System

A full-stack hotel management system with booking, transport, and admin modules using the MERN stack and Tailwind CSS.

## 🛠️ Tech Stack

- ⚛️ React.js
- 🟢 Node.js
- 🚂 Express.js
- 🍃 MongoDB
- 🎨 Tailwind CSS

## ✨ Features

- Hotel and room management
- Online room reservations
- Transport booking
- User authentication
- Admin dashboard
- Booking management
- Reporting and analytics
- Responsive user interface
